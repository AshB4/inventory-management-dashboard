# Capstone Project

Initial skeleton for a Flask backend and React frontend.

## Structure

```text
capstone-project/
├── backend/
├── frontend/
├── n8n_workflow.json
└── README.md
```

## Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Frontend

```bash
cd frontend
npm install
npm start
```
